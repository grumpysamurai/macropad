# macropad
A macropad made with a esp32, the goal is for this macropad to have a display rgb lights and a dial to change macros and light modes.
So far I have just created a virtual design in WOKWI, I am now working on code for it to have a user interface to allow for the changing of different settings.
Another feature I would like to add is the ability for a user to edit a json file and create their own custom macro extremely easily.
